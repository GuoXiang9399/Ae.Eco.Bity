# Ae.Eco.Bity

Hourly Host-Seeking Activity of Aedes albopictus in Guangzhou (2016–2018)

This repository contains the underlying row-level dataset used in the following study:

A field-based modeling study on ecological characterization of hourly host-seeking behavior and its associated climatic variables in Aedes albopictus. Parasites & Vectors, 12, 474. https://doi.org/10.1186/s13071-019-3715-1

Mosquito samples and data on mosquito hourly density and site-specific climatic variables were collected simultaneously in urban outdoor environments in Guangzhou during 2016–2018. The dataset comprises 624 longitudinal hourly observations and 288 multisite hourly observations.
